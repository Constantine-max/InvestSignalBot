# InvestSignalBot

Telegram-бот на Python, который показывает топ-10, топ-50 или топ-100 криптовалют по рыночной капитализации. Рыночные данные загружаются из публичного API CoinGecko.

## Возможности

- интерактивное меню Telegram;
- актуальный рейтинг криптовалют;
- отображение цены в долларах США;
- обработка ошибок API без падения бота.

## Запуск

1. Установите Python 3.10 или новее.
2. Создайте виртуальное окружение и установите зависимости:

~~~bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
~~~

3. Создайте нового бота через BotFather и задайте токен только через переменную окружения:

~~~powershell
$env:TELEGRAM_BOT_TOKEN = "your-new-token"
python crypto.py
~~~
